## 独立レビューと修正

編集設計と全20ページ・ナビゲーションを独立レビュアーへ渡した。ページ単位に再分割・再統合を要する重大問題はなかったが、読者経路に3点の不足が見つかった。

1. **Codex の入口**：インストール後に Claude 前提の手順しか選べなかった。quick-start に Codex の設定作成、認証条件、起動、自動 UI、拒否先の調査、codex への通信設定、応答確認を追加した。
2. **一時承認の条件**：profiles 冒頭が直接拒否された要求も UI で許可できるように読めた。Pending に届く要求に限定し、直接拒否には設定変更が必要と明示した。再確認で一時承認の主語も明記した。
3. **Worktree の終了**：保存の選択がどこに出るかが不明だった。実装を別途確認し、CLI / UI それぞれのターミナルで Keep に回答し、表示された保存先を確認する手順へ修正した。Delete 選択時の段階と、ブランチだけが残る条件を明示した。

修正後に再レビューし、3点の解消と新たな重大な逆行がないことを確認した。通常起動と同時の UI 自動起動、ブラウザ入力だけに必要な dtach、手動 nas ui を接続問題の補助手順に置く構成も確認対象とした。
