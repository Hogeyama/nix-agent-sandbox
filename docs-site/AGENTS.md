# docs-site の執筆

文章の新規作成・再構成には [reader-decision-writing](../skills/reader-decision-writing/SKILL.md) を適用する。[ページの編集設計](editorial/pages.md)で、そのページの読者と目的を先に確認する。

- トップの目的は「自分に使う価値・試す価値があるか」の判断。製品の定義、機能一覧、リンク案内は目的の代用ではない。
- 見出し・ページタイトル・ナビゲーションは名詞句。動詞を使わない。本文にはこの制限を広げない。
- 宣伝調の見出し、抽象的な効能、根拠のない安全性・手軽さ・所要時間を加えない。
- 紹介、仕組みの説明、設定手順、運用を分ける。情報の採否はページの目的で判断する。
- 編集の設計・評価記録は `editorial/` に置く。公開本文に編集者向けのチェックリストを入れない。

文章の修正では `bun run docs:build` と `git diff --check` を確認する。Pkl の例を変更したら、実際の記載位置に合わせてスキーマで評価する。これらだけで文章の目的達成を判定しない。
