nas は、AI エージェントにコードの編集やテストを任せながら、読ませるファイルや外部への通信を制限するツールです。プロジェクトの秘密情報を渡すことや、作業に関係のない相手への送信が気になる場合に使えます。

## 用途

- **秘密ファイルの非公開**：ソースコードの編集は任せつつ、`.env` などのファイルをエージェントから隠せます。
- **通信先の制限**：必要な API やパッケージ配布元への接続を許可し、それ以外は拒否するか、その都度承認する設定にできます。
- **認証が必要な作業**：デプロイ用の認証情報をエージェントに渡さず、承認したデプロイコマンドの実行時にだけ渡せます。

## 対応環境

Linux と Docker が必要です。Claude Code、GitHub Copilot CLI、OpenAI Codex CLI に対応しています。Nix は任意です。

## 起動までの作業

nas を導入し、プロジェクトごとの設定ファイルを作成します。その中で、エージェントの API など、必要な通信先を許可してから起動します。秘密ファイルの非公開や、認証が必要なコマンドも自分で設定します。

設定した範囲でエージェントが作業し、承認待ちにした通信やコマンドだけを実行時に確認します。作業で新しい接続先やコマンドが必要になった場合は、設定の追加や承認が必要です。
