AI エージェントにコードの編集やテストを任せるとき、秘密ファイルまで読ませたくない、外部への送信や認証を使う操作は自分で判断したい。nas は、エージェントを隔離した作業環境で動かし、任せる範囲を設定するためのツールです。

## エージェントの作業範囲

ソースコードを編集できるようにしたまま、`.env` などの秘密ファイルを隠せます。外部への通信は必要な接続先を許可し、それ以外を拒否するか、実行時に人が確認する設定にできます。

認証情報が必要なビルドやデプロイも、値をエージェントへ読ませず、許可したコマンドの実行時に渡せます。実行内容を確認してからホストで動かす場合は、承認待ちにするルールを設定します。

## 作業中の判断と確認

エージェントを起動すると、ブラウザ用の UI も自動で起動します。UI ではセッションごとの要求を確認し、通信やホストコマンドを許可・拒否します。一回だけ許可するか、そのセッションで同じ条件の要求にも適用するかを選べます。

エージェントが作った開発サーバーは、UI のポート公開欄からブラウザで開けます。承認待ちへの対応と、できあがったページの確認を同じ画面から進められます。

## 利用の前提

Linux と Docker が必要です。Claude Code、GitHub Copilot CLI、OpenAI Codex CLI に対応し、Nix は任意です。

最初にプロジェクトの設定を作り、エージェントの API への通信を許可します。秘密ファイルの非公開やホスト実行のルールも自分で設定します。作業に必要な接続先やコマンドが増えたら、設定の追加や実行時の承認で対応します。
