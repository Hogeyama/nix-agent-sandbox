nas は AI コーディングエージェントを Docker サンドボックス内で実行する CLI です。作業対象のワークスペースはエージェントへ読み書き可能にマウントされます。さらに存在する場合、選択したエージェントのホスト設定・認証ディレクトリ（`~/.claude`、`~/.codex`、または旧 `~/.copilot`。Claude では `~/.claude.json` も）は読み書き可能でマウントされ、`~/.config/git` は読み取り専用でマウントされます。それ以外のホストファイルシステムと外部ネットワークは最初は利用できません。ネットワーク接続、追加のホストパス、Docker in Docker などは設定で明示的に有効にします。ただし Nix 統合は既定で `"auto"` です。ホストで Nix が検出されると有効になり、既定の `mountSocket = true` により `/nix` がマウントされます。

## 最初の 3 ステップ

<Steps>

1. [nas をインストールする](./getting-started/installation/)

2. 作業したいプロジェクトのルートで設定を生成します。

   ```sh
   nas config init
   ```

3. エージェントを起動します。

   ```sh
   nas
   ```

</Steps>
