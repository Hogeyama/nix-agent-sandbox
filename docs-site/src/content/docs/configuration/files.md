---
title: ファイルの共有と非公開
description: 共有するファイル、読み書き権限、ファイル全体の非公開と秘密値のマスク
---

作業フォルダーは既定で読み書き可能です。エージェントによる変更はホストに残ります。必要なファイルを追加で渡すか、作業フォルダー内の秘密を読ませないようにするかで設定を選びます。

| 必要な変更 | 設定 |
| --- | --- |
| キャッシュなどを追加で渡す | [ファイルの追加共有](#ファイルの追加共有) |
| .env などを丸ごと読ませない | [ファイル全体の非公開](#ファイル全体の非公開) |
| ファイルの構造は見せて、秘密値だけ隠す | [値のマスク](#値のマスク) |

以下は[対象プロファイル](/nix-agent-sandbox/configuration/profiles/#プロファイルの編集)へ追加する設定です。

## ファイルの追加共有

読むだけでよいキャッシュは、読み取り専用で共有します。`ro` でもファイルの内容は読めるので、秘密のあるフォルダーをそのまま共有しないでください。

```pkl
extraMounts {
  new { src = "~/.cache/my-tool"; dst = "~/.cache/my-tool"; mode = "ro" }
}
```

`src` は実際に使うホストのパスへ置き換えます。`dst` がコンテナ側のパスです。書き込みも任せる場合だけ `mode = "rw"` にします。rw はホストの実体へ書き込むため、後でホストのツールが読むキャッシュにも影響します。

| 項目 | パス・権限 |
| --- | --- |
| `src` | ホスト側。絶対パス、`~`、または `workDir` 基準の相対パス。 |
| `dst` | コンテナ側。相対パスはコンテナの作業ディレクトリ基準。 |
| `mode` | 既定は ro。rw は書き込みも可能。 |

設定を再信頼して起動し、エージェントから共有先を読めることを確認します。存在しない src は警告してスキップされるため、起動ログも確認してください。

## ファイル全体の非公開

作業フォルダーの `.env` を読ませない場合は、空のファイルで覆います。同じプロファイルの extraMounts に追加します。

```pkl
extraMounts {
  new { src = "/dev/null"; dst = ".env"; mode = "ro" }
}
```

`dst = ".env"` は作業ディレクトリの .env です。起動後、エージェントからは空のファイルとして見えます。ホストの元ファイルを消す設定ではありません。

その値をビルド時に使いたい場合は、ファイルを公開する代わりに[必要なホストコマンドへ注入](/nix-agent-sandbox/configuration/host-commands/#秘密値付きのビルド)できます。

## 値のマスク

ファイルの他の部分を読ませながら値だけを隠す場合は、名前付き秘密を登録して mask を設定します。次は .env の API_TOKEN と一致する値を、ファイル表示とコマンド出力で隠す例です。

```pkl
secrets {
  ["api-token"] { from = "dotenv:.env#API_TOKEN"; required = true }
}

mask = new MaskConfig {
  maskfs = true
  proxy = true
  filter = true
  apply = new Listing { "api-token" }
  writePolicy = "readonly"
}
```

起動後、登録した値は同じ長さの `*` に見えます。名前を secrets に登録しただけでは、ファイル表示やコマンド出力はマスクされません。登録先を変える場合は[秘密値の取得元](/nix-agent-sandbox/configuration/authentication/#秘密値の取得元)を参照してください。

### 編集への影響

マスクはファイルの別コピーを作る処理ではなく、読み取り時の表示変更です。元は未変更のファイルが、Git では差分に見える場合があります。

既定の **`writePolicy = "readonly"` はマスク対象ファイルの変更を拒否します。** `"passthrough"` にすると、表示された `*` をエージェントが実ファイルへ書き戻して壊す場合があります。

### マスク範囲の変更

mask を指定すると `maskfs`、`proxy`、`filter` は既定で true、`apply` はすべての名前付き秘密です。`apply` でファイル表示と出力フィルターの対象を絞れます。HTTP 通信ごとの秘密の扱いは[通信側の設定](/nix-agent-sandbox/configuration/network/#認証ヘッダーと秘密値)で選びます。

mask を省略するとファイル表示と出力フィルターは無効ですが、プロキシのマスクは既定で有効です。`mask.maskfs = false` ではファイル内の秘密値が見えるようになります。`mask.proxy = false` にする場合は、ネットワーク側の mask / forbid 指定も変更する必要があります。

`.nas/config.pkl` は読み取り専用で保護されますが、ホストコマンドが読む他のスクリプトや設定は自分で保護します。[ホスト実行の入力保護](/nix-agent-sandbox/configuration/host-commands/#実行前の条件)を参照してください。
