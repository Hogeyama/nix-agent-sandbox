# 脅威モデルの要約スライド

タイトル・目的2枚、本編11枚、付録5枚の計18枚。[脅威モデル](../threat-model.md)を初めて読むClaude Code利用者向けに、仮定、要求水準の選択、仕様・実測、条件付きの評価の順に整理した。

比較表の◎・○は、指定した条件への適合を判断したもの。全項目を実測した結果ではない。Docker Sandboxの例で、無効なtokenに対する401の観測から、有効な攻撃者tokenを想定した評価に至る過程と、未検証の範囲を分けて示している。
